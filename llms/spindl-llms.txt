# Spindl

> Spindl is an onchain growth platform — attribution, Web3-native analytics, audiences, short links, referrals and ads in one place. Web2 had Mixpanel and Amplitude; Spindl is the Web3 equivalent, used by teams including Uniswap, Base, Safe, Morpho and Coinbase Wallet. Spindl joined Coinbase in January 2025 and operates as a product team inside Base. Generated by the API Evangelist enrichment pipeline on 2026-08-13; the previous version of this file pointed at GitBook URLs that no longer exist.

## APIs

- [Spindl Ads (Embed) API](https://docs.spindl.xyz/ads/start-here): Publisher API. GET https://e.spindlembed.com/v1/render/{publisher_id} returns targeted ad recommendations for a wallet at a placement; POST /v1/external/track records impressions and clicks; GET /v1/serve renders a hosted iframe unit. Auth header X-API-ACCESS-KEY. LIVE.
- [Spindl Custom Events API](https://docs.spindl.xyz/technical/api/custom-events-api): POST https://spindl.link/events/server ingests an array of custom attribution events identified by wallet address or customerUserId. Auth header X-API-Key. LIVE.
- [Spindl Short Links API](https://docs.spindl.xyz/technical/api/short-links): GET/POST https://api.spindl.xyz/v1/links creates and lists short redirect links. Auth header X-API-Key. This host returned HTTP 503 on 2026-08-13.
- [Data Exports](https://docs.spindl.xyz/technical/api/data-exports): Daily full dump of client and blockchain events to a shared AWS S3 bucket, .csv or .parquet, ~8h delayed. Not an API — a file delivery.
